# LiveWall — инструкция: от папки до живых обоев на iPhone

Папка проекта уже лежит на рабочем столе: `C:\Users\Danil\Desktop\LiveWall`

Ниже — два пути. Первый (рекомендуемый) не требует Mac: IPA собирается бесплатно в GitHub Actions,
а подписывается на вашем Windows-ПК через Sideloadly.

---

## Часть 0. Что понадобится

- iPhone с iOS 17 или новее.
- Apple ID (обычный, бесплатный — подходит).
- Windows-ПК с интернетом.
- 15–20 минут времени.

---

## Часть 1. Собрать IPA без Mac (GitHub Actions)

### Шаг 1.1. Зарегистрироваться на GitHub

1. Откройте https://github.com → **Sign up** (если аккаунта ещё нет).
2. Подтвердите e-mail.

### Шаг 1.2. Создать репозиторий

1. Нажмите **+** справа сверху → **New repository**.
2. Имя: `livewall` (любое).
3. Выберите **Private** (можно и Public — не важно).
4. **Create repository**. Ничего не добавляйте при создании (без README).

### Шаг 1.3. Загрузить проект

**Вариант А — через сайт (проще всего):**

1. На странице пустого репозитория нажмите **uploading an existing file**.
2. Откройте в Проводнике `C:\Users\Danil\Desktop\LiveWall`.
3. Выделите **всё содержимое папки** (Ctrl+A) и перетащите в окно браузера.
   Важно: перетаскивать нужно содержимое, а не саму папку `LiveWall`.
   Папки `.github`, `LiveWall`, `LiveWall.xcodeproj`, `tools` должны попасть в корень репозитория.
4. Внизу нажмите **Commit changes**.

**Вариант Б — через GitHub Desktop (удобнее для правок):**

1. Установите https://desktop.github.com
2. **File → Add local repository** → выберите `C:\Users\Danil\Desktop\LiveWall`.
3. Он предложит создать репозиторий — согласитесь (**create a repository**).
4. Нажмите **Publish repository**, снимите галочку «Keep this code private» при желании.

### Шаг 1.4. Запустить сборку

1. В репозитории откройте вкладку **Actions**.
2. Если сверху написано про workflows — нажмите **I understand my workflows, go ahead and enable them**.
3. Слева выберите **Build IPA** → справа **Run workflow** → **Run workflow**.
4. Обновите страницу через 10 секунд — появится запуск с жёлтым кружком.

Сборка идёт 3–7 минут. Зелёная галочка = успех.

### Шаг 1.5. Скачать IPA

1. Откройте завершившийся запуск.
2. Внизу, блок **Artifacts** → **LiveWall-unsigned-ipa**.
3. Скачается ZIP. Распакуйте → внутри `LiveWall.ipa`.

> Если сборка упала (красный крестик) — откройте лог, скопируйте последние 40–50 строк
> и пришлите мне: поправлю проект.

## Часть 2. Подписать и установить (Sideloadly, Windows)

### Шаг 2.1. Подготовить компьютер

1. Установите **iTunes** именно с сайта Apple (не из Microsoft Store):
   https://www.apple.com/itunes/download/win64
   Нужны драйверы Apple Mobile Device.
2. Установите **Sideloadly**: https://sideloadly.io
3. Перезагрузите ПК (чтобы поднялись службы Apple).

### Шаг 2.2. Подключить iPhone

1. Кабель в ПК, на iPhone нажмите **Доверять этому компьютеру** и введите пароль.
2. В Sideloadly сверху должен появиться ваш iPhone (имя и iOS).

### Шаг 2.3. Подписать

1. Перетащите `LiveWall.ipa` в окно Sideloadly (или нажмите папку и выберите файл).
2. В поле **Apple ID** введите свой Apple ID.
3. Нажмите **Start**.
4. Введите пароль Apple ID. Если включена двухфакторная аутентификация — попросит код,
   а иногда нужно создать «пароль приложения» на https://appleid.apple.com
   (Раздел **Безопасность → Пароли приложений**).
5. Дождитесь надписи **Done**.

### Шаг 2.4. Доверить приложению

На iPhone: **Настройки → Основные → VPN и управление устройством → Разработчик … → Доверять**.
После этого иконка LiveWall запустится.

> Бесплатный Apple ID: приложение работает 7 дней, потом нужно снова нажать Start в Sideloadly
> (данные внутри приложения при этом сохраняются не всегда — созданные Live Photo остаются в «Фото»).

## Часть 3. Сделать живые обои

1. Откройте **LiveWall**.
2. Нажмите **Видео** (или **Фото**) и выберите материал из «Фото».
   - Видео лучше вертикальное, 2–3 секунды, без резкой тряски.
   - Фото превратится в плавный зум (эффект Кена Бёрнса).
3. Слайдерами выберите **начало** и **длительность** (1–5 с).
4. **Масштаб кадра**: «Заполнить» — на весь экран без полей, «Вписать» — с чёрными полями.
5. Нажмите **Сделать Live Photo** и дождитесь 100%.
6. Разрешите доступ к Фотоплёнке, если спросит.
7. Вкладка **«Как установить»** — там те же шаги, что ниже.

### Установка обоев

1. **Настройки → Обои → Добавить новые обои → Фото**.
2. Выберите свежее фото — в углу должен быть значок **LIVE**.
3. Внизу экрана нажмите кнопку **Live Photo**, чтобы она стала активной (без перечёркивания).
4. **Добавить → Установить как пару обоев**.
5. На экране блокировки анимация запускается при пробуждении телефона или долгом нажатии.

## Если что-то не работает

| Проблема | Решение |
|---|---|
| Sideloadly: `Unable to connect to device` | Переустановите iTunes с сайта Apple, перезагрузите ПК, другой кабель/порт USB |
| `Invalid Apple ID or password` | Включена 2FA — создайте «пароль приложения» на appleid.apple.com |
| `This app cannot be installed because its integrity could not be verified` | Доверьте профилю: Настройки → Основные → VPN и управление устройством |
| Приложение «вылетает» при запуске | Скорее всего подпись просрочена — подпишите заново в Sideloadly |
| Live Photo не анимируется | Проверьте кнопку **Live Photo** при установке; отключите «Универсальный доступ → Движение → Уменьшение движения» |
| Фото в «Фото» без значка LIVE | Live Photo не собрался — пришлите текст ошибки из приложения |
| Сборка в Actions красная | Пришлите лог, исправлю |

## Технические детали (если интересно)

- Проект: SwiftUI, iOS 17+, `LiveWall.xcodeproj`.
- Live Photo собирается как пара файлов: JPEG с `MakerApple["17"] = <uuid>` и MOV
  с `com.apple.quicktime.content.identifier = <uuid>` и тайм-метаданными
  `com.apple.quicktime.still-image-time`.
- Сохранение: `PHAssetCreationRequest` → `.photo` + `.pairedVideo`.
- Звук не переносится (для обоев не нужен).
- Bundle ID: `com.danil.livewall` (меняется в `project.pbxproj` или в Xcode → Signing).
